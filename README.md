# Manufacturing KPI Dashboard

A Streamlit dashboard for analyzing manufacturing performance metrics and visualizing production data.

## Features
- Upload manufacturing data using CSV files
- Calculate manufacturing KPIs
- Track total production
- Monitor defect rates
- Visualize production by machine

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

## Skills Demonstrated
- Manufacturing Analytics
- Data Visualization
- KPI Development
- Python Programming
- Dashboard Design
